# Meme Generator

A React app for generating memes, built with [Vite](https://vite.dev).

## Scripts

Install dependencies with `pnpm install`, then:

- `pnpm dev` (or `pnpm start`) – start the dev server at http://localhost:5173
- `pnpm build` – build for production into the `build` folder
- `pnpm preview` – preview the production build locally
